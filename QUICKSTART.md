# Baranchik Sound

Музика та автоматичне оповіщення про тривогу.

## Быстрый запуск

## 1. Подготовьте файлы

Проект требует Node.js 18+ и npm 9+.

- Скопируйте три сигнала в `public/sounds/`:
  - `Tryvoga-Kremenchuk-Yellow.mp3`
  - `Tryvoga-Kremenchuk-Red.mp3`
  - `Tryvoga-Vidbii_01.mp3`
- Музыку в проект добавлять не нужно: персонал выберет аудиофайлы на телефоне после открытия страницы.
- Добавьте файлы приветствий в `public/gamarjos/`. Папка может оставаться пустой.

## 2. Выберите локацию и настройте доступ

В «Налаштуваннях» выберите область, район и громаду/город. Сопоставление тревог идёт по UID выбранного места и родительской цепочке; без выбора запросы к API не выполняются. Если `locations.json` недоступен, повторите загрузку или введите числовой UID вручную.

Для direct API получите токен в кабинете разработчика на [devs.alerts.in.ua](https://devs.alerts.in.ua/), введите его в настройках и сохраните. Можно открыть одноразовую ссылку с `#t=...`: сайт сохранит токен и очистит фрагмент адреса. В proxy-режиме токен в браузере не нужен; proxy URL задаётся в `public/venue.json`, а не в UI.

Для публичного сервиса используйте Worker: устройства одной сети делят API rate limit. Приложение ограничивает свои обращения восемью запросами за 60 секунд, но это не объединяет IP-лимиты нескольких устройств.

## 3. Соберите и проверьте сайт

```sh
npm run build
```

1. Выполните `npm run build`.
2. Опубликуйте папку `dist` (например, через Netlify Drop).
3. Откройте сайт на iPhone.
4. Выберите локацию в настройках; затем введите токен для direct API или используйте настроенный Worker.
5. Коснитесь экрана, чтобы разблокировать звук.
6. Откройте «Діагностика» → «Самотест».

Для iOS 12 используйте только собранную версию, не Vite dev server. Токена в коде и `dist` нет.

После первого касания нажмите «Вибрати музику» и выберите один локальный аудиофайл, затем нажмите «Грати». Файл должен быть доступен в приложении «Файлы»; загрузите его из iCloud перед выбором. Музыка зациклена, новый выбор останавливает и заменяет текущий файл. После reload выберите файл снова. Во время сигнала тревоги и «Гамарджос» музыка прерывается и возвращается с той же позиции, если до этого была запущена кнопкой «Грати».

## 4. Настройте iPhone

1. Подключите зарядку и выключите «Режим энергосбережения».
2. В «Автоблокировании» установите «Никогда».
3. Включите автоматические дату, время и часовой пояс.
4. Отключите автоматические обновления iOS и уведомления; режим «Не беспокоить» оставьте выключенным.
5. Включите «Керований доступ» и заблокируйте Safari на странице тройным нажатием кнопки «Додому».
6. Оставьте Safari открытым на странице и подключите стабильный Wi-Fi.
7. Выставьте системную громкость физическими кнопками. Приложение не может менять её.
8. После каждого перезапуска телефона или страницы коснитесь экрана и выберите музыкальные файлы заново.

На iOS 12 экран блокировать и Safari сворачивать нельзя: система может остановить страницу и звук. Лицензия на публичное воспроизведение музыки — ответственность заведения.

## 4. Симуляция

Откройте `?sim=1` после URL сайта, чтобы получить кнопки симуляции состояний и «Прогнати сценарій». Панель «Самотест» доступна в «Діагностика».

Запросите секреты GitHub Actions `NETLIFY_AUTH_TOKEN` и `NETLIFY_SITE_ID` у администратора репозитория для автоматического Netlify deploy; API-токен тревог этим секретам не заменяет.
